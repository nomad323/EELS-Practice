# Validation

No validation has been performed.

For each actual check, record the requirement, environment/version, command or reviewed procedure, input/fixture provenance, expected behaviour, observed outcome, limitations, and checker/date.

Keep these levels separate:
- Unit/algorithm tests.
- Offline regression tests using mocks, replay, or simulation.
- Deployment and operator-supervised hardware acceptance, only with separate explicit approval.

Document the known-good baseline and rollback/restore procedure before rollout. A passing mock test is not hardware acceptance or proof of safety.
