# 0001 — 合成能量响应模型与本地浏览器界面

状态：首版实现选择；真实仪器模型仍待资料和标定。

## 依据

用户授权 WSL2 本地浏览器实施，确认 8 meV 指无残余像差时的全显示纵向积分总 FWHM。原脚本只有任意单位的五维光线模型，狭缝位置/传递系数没有仪器溯源；其 `0.3*x_slot` 已包含有效能量系数 0.36，直接再加入总色散容易重复计入。原件不覆盖。

## 决定

1. 保留原默认数值路径为 `legacy.py`，与新有效能量模型分开。新版复用角度单项式思想及严格别名映射，但不把原脚本任意单位做表面重命名而称为 meV。
2. 新版将角度多项式位移定义为能量等效位移。固定总高斯响应描述默认 8 meV；在几何落点后卷积，是对独立能量随机量进行数值边缘化。基线不是 Cc 标定，也不是对源/探测器/真实色差的唯一分解。
3. 用四重对称配对的圆孔径 Monte Carlo 采样，缓存九项基函数；拖动时固定采样。保留真实对称性，避免把随机采样不对称误当作九参数可唯一辨识的依据。高质量档位减少有限采样误差。
4. 亚像素能量落点采用线性分配，卷积用零填充 FFT；在扩展视野上卷积后再裁切，避免周期回卷，也允许视野外光线模糊进入视野。离散像素和有限采样误差通过收敛检查约束；未声称模拟真实探测器 MTF。
5. 基线总计数按入射计数定义，角接受窗口导致实际透过率变化，不把截掉的光线重新归一化补回来。全显示纵向像素积分得到与显示同源的谱；只扣除已知合成均匀背景，不从任意实验谱自动估计背景。
6. 训练控制的是有效 Dij 补偿量，不是硬件旋钮；先采用恒等响应 r=a+c。随机强度同时受难度和视野约束，各难度有不同视野预算，避免统一裁切预算使九项题的难度全部塌缩为同一组系数。
7. Python 标准库 HTTP + 已有 NumPy/Pillow + 原生 JS/Canvas；不为界面安装框架。默认只绑定回环地址，静态资源白名单，同源/Host 检查，无上传、任意文件读取或后台硬件接口。此标准库服务不是公网生产服务器。
8. 核心与浏览器分离。NPZ 保存线性数据与 Unicode JSON 元数据，无 pickle。题目标签默认留在服务端，按需反馈/导出；本地用户仍可检查程序或从种子重现，因此不把隐藏题目称为密码学防作弊机制。

## 取舍和延期

- 有效总响应使首版可练习、可验证，但不能替代含真实 Cc、有限源、能量狭缝、校正器耦合和衍射的仪器模型。
- 首版界面角接受窗口明确不是原能量狭缝；不在无几何资料时增加看似真实的错误模块。有限源/完整能角传递暂不接入主界面。
- FWHM 只在有效半高连通区、足够信号和未明显截断时报告。低于半高的次峰/长尾仍可能被 FWHM 忽略，所以另显示 RMS、质心与原始形状。
- 只记录离线验证；Windows→WSL2 访问及用户交互习惯需要目标机器验收，真实实验准确性需要另行数据和流程。
