# 0004 — Windows 轻量便携版与浏览器页面生命周期

状态：已实现。Linux 离线验证及 Windows x64 构建完成，生成 exe 的离线自检、隔离 Windows Edge/Chrome 检查通过；用户默认浏览器关联和实际桌面操作仍待确认。

## 需求来源与边界

用户要求现有程序在 Windows 上作为软件运行，直接打开浏览器，关闭对应网页同时结束程序，避免臃肿。用户没有指定打包器、浏览器内核或精确退出延迟。以下是实现选择，不冒充用户指定的技术细节。原有 WSL 手动入口、算法、仪器隔离及原始数据保护保持不变。

## 选择

- 保留 NumPy/Pillow 及标准库 HTTP 后端、原生 JS/Canvas，增加独立 `run_desktop.py`。PyInstaller 在 Windows 构建 `onedir + windowed` 便携文件夹，再 ZIP 分发；最终用户只需已有默认浏览器。不引入 Electron、Chromium、WebView、Node 运行时或 GUI 框架。
- 不以 onefile 外观当作体积优化：它仍需带相同运行库，且每次启动要解压。目录版允许直接运行、容易检查/回退，但用户必须保留 `_internal` 并移动整个目录。实际大小由构建报告测量，不预先承诺。
- 独立干净构建 venv，构建依赖与运行依赖分开，脚本不自动安装。打包数据明确只收集网页资源，第三方许可证单独收集；不把 raw、测试、截图、科研资料、Git 或开发环境打进成品。构建先测试，再运行生成二进制的离线自检；失败不产出分发 ZIP，已有输出不覆盖。
- 使用默认浏览器打开 `127.0.0.1` 自动空闲端口，避免固定端口冲突。每次双击独立实例，不做单实例锁、注册表、后台服务或托盘常驻。
- 每个页面打开带随机实例令牌的 SSE 连接，由服务器每秒小包写入探测 socket；后台 JS 不必周期执行。页面 `pagehide` 关闭事件流，`pageshow` 重连。刷新保留 fragment，连接成功即取消退出；关闭/崩溃导致最后一条连接消失后再留 5 秒宽限。
- 不仅依赖 unload/beacon，因为崩溃时可能没有通知；也不使用短 JS 心跳超时，因为后台节流会误退出。SSE 复用标准库和浏览器能力，不增加 WebSocket 依赖。进程退出不等于关闭浏览器，不杀默认浏览器或无关标签。
- 首次页面 90 秒未连接则退出并提示；连接断开加 5 秒宽限通常约 5～10 秒退出，而非零延迟。普通后台/冻结 JS 已测，但浏览器主动丢弃页面、网络进程冻结、断网或 OS 休眠不能等同正常后台保活；恢复时可能需要重新双击程序。刷新/退出仍丢失未导出的内存会话。
- 令牌仅用于区分/保护实例生命周期，不替代已有接口校验：SSE 同样校验 Host、Origin、Sec-Fetch-Site，HTTP 日志不记录令牌。令牌不是仪器访问权限或公网安全方案。

## 代价与回退

需要在 Windows 上构建并验收；Linux 源码测试不能证明 DLL 收集、杀毒/签名信誉、默认浏览器关联或目标机退出行为。无 Windows 二进制即不报告成品体积或成功分发。保留旧包，直接停止新 exe 后使用旧便携文件夹；源码仍可运行原 `python3 run.py`，按 Ctrl+C 手动退出。后续 Windows 构建经用户批准在独立 venv 安装了构建依赖，未改变原 WSL 或系统 Python 环境。没有模型/标定替换、部署或硬件操作。
