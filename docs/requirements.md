# EELS 像差练习软件 — 需求与模型边界

## 授权与平台

用户确认：在 WSL2 中运行、本地浏览器访问；可以开始实施。8 meV 指无残余像差时，沿非色散方向积分后的整个 ZLP 的 FWHM。保留 `raw/20260912/` 原件；不安装新依赖，不控制仪器，不训练神经网络。浏览器只访问回环地址，不加载 CDN、字体或外部服务。

## 首版验收

- 九个有正负号的滑块及数值输入，任意叠加：`D10,D01,D20,D11,D02,D30,D21,D12,D03`。支持单项/全部归零。
- 自由模式直接调整残余系数；练习模式随机生成隐藏初始像差 a，滑块调整补偿 c，实际残余 r=a+c，理想答案 c*=-a。按需揭示逐项答案、残差和归一化 RMS 误差。支持单项/三项/九项、难度、种子、新题和重试。
- 隐藏答案不出现在常规图像 API 响应中；主动揭示或导出带标签样本才返回答案。隐藏用于练习，不是防作弊安全系统。
- 黑底白亮信号，二维光斑与同源积分谱、FWHM、半高交点、质心和 RMS 宽度同屏。显示 gamma/强度不改变计数或宽度测量。
- 零系数、默认场景、无计数噪声时 FWHM 软件验收目标 `8.0 ± 0.2 meV`；此容差不是实验标定精度。更改额外展宽/孔径等场景后不强制维持 8 meV。
- 所有宽度由线性数据测量；半高区多段、交点缺失、明显低计数、视野截断时标警告或不给出有效 FWHM。FWHM 不是唯一调节评分。
- 固定题目/采样/噪声种子；拖动不重新生成题目。状态和结果串行更新，避免旧响应覆盖新参数。
- 交互改进：按住鼠标连续拖动期间即更新光斑、谱线、FWHM 和已揭示的答案表，不等待输入停止。最多一个请求在途，仅保留下一次的最新输入；同一模式/题目/场景内允许显示已完成的中间帧，但不写回覆盖用户的新控件值。模式、题目、场景或其他显式操作变更后丢弃旧上下文帧。停止输入后必须显示最终参数对应帧；所有图谱指标同源，不为实时显示暗中降低采样质量。
- 滚轮会话通过九项各自的“滚轮调节”按钮启用，不再通过双击启用；最多一项活动，有高亮及全页浮动提示。每行常驻独立步长（默认 0.1 meV，0.01～120、精度 0.01），不折叠行。活动期间在 document 捕获滚轮，无论指针位于光斑、其他系数或步长输入框，都只调选中项，不产生页面或原生输入框滚动。上滚增加、下滚减少，限制系数在 ±120；非法步长不执行。
- 启用时保存当前九项系数快照，而非可能较旧的显示帧。下一次左键在页面任意位置点击，保留本次结果并停止，且消费该次点击，不能顺带归零、换题、切换项或重新启用。Esc 撤销并恢复本次启用快照，重新同步图谱、FWHM 和答案残差；已结束的会话不能被之后的 Esc 撤销。撤销必须使在途旧调节帧失效，防止旧响应覆盖恢复后的状态。练习题目、随机种子及答案显示状态不因撤销而重置。
- 调节期间拦截全页滚轮的默认滚动/缩放；水平滚轮及 Ctrl/Meta 修饰滚轮不改变系数。结束后恢复正常滚动/缩放。窗口失焦或显式模式/场景操作安全结束会话并保留当前值，防止恢复跨上下文快照。步长不属于物理系数快照，也不写入模型或训练标签。
- 连续调节时图谱/答案表为最近完成帧，控件为最新输入，界面明确提示；未同步到最终输入前不可导出。实际更新速率取决于浏览器、计算和 WSL 转发，不作固定帧率承诺。
- 提供无界面 NumPy 核心和 NPZ 导出，包含原始观测、期望计数、能量/纵向坐标、积分谱、系数、种子、配置及模型版本。不以灰度 PNG 代替训练输入。
- 原脚本数值部分保留为独立 legacy 回归模式，新版不依赖 raw 目录运行。

## 数学约定

`u,v` 为参考圆孔径归一化的角坐标；所有 Dij 为 **meV / 归一化角度幂**（归一化角度无量纲），无阶乘：

```
P(u,v) = D10*u + D01*v + D20*u² + D11*u*v + D02*v²
       + D30*u³ + D21*u²*v + D12*u*v² + D03*v³
E_detector = P(u,v) + ε,    y_detector = v
```

默认 `ε` 是 FWHM=8 meV 的高斯有效总能量响应，σ=8/√(8 ln 2)≈3.397 meV。通过对几何落点分布进行固定高斯卷积来边缘化能量随机量，比重复抽取有限能量光线更稳定；不在每次拖动后重标定横轴。探测器图是期望计数，开启 Poisson 后是计数实现。

**8 meV 不是 Cc。** 首版不将源、色差、探测器分别各设为 8 meV。基线表示合并的有效响应；额外高斯能量模糊可按方差合成，像素化另行作用。真实能角色差耦合、设备传递矩阵、校正器耦合、衍射和实验标定不在首版中冒充实现。

## 合成情景

支持横/纵孔径比例、几何非色散方向狭窄接受窗口、额外能量高斯响应、非色散方向高斯 PSF、总计数、均匀背景、Poisson 噪声和视野大小。窗口明确是 `|u|` 角接受窗口，**不是原脚本的能量选择狭缝**；原能量选择模型仅在 legacy 模式保留。有限源/完整能角相关狭缝与真正色差耦合需进一步模型审查，首版不以错误代理冒充。

滑块量程和情景范围是合成练习设置，不是设备安全限值。随机题按孔径和视野约束初始几何位移；大补偿仍可能出视野，此时明确提示被裁切比例。纵横轴单位不同，显示尺寸只是显式的能量—角度图布局，不能当作真实探测器几何放大率。

## 已知不可辨识性

对称孔径下，同时改变所有 u 的奇次幂项的符号可产生相同图像，因此单张图不保证唯一九参数反演。界面将“与生成标签的差距”和可观察的谱宽/形状分开；后续网络需处理等价解、额外观测或调节轨迹。生成标签误差不能解释为实验像差测量误差。

## 验证层级

数值单元测试 → legacy 离线回归 → 本地 HTTP/浏览器交互验证 → 用户在 Windows 浏览器经 WSL2 localhost 操作验收。前三级不等于真实仪器或实验准确性验收。实际记录见 `docs/validation.md`。
