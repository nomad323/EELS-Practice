## 数学约定

`u,v` 为参考圆孔径归一化的角坐标；所有 Dij 为 **meV / 归一化角度幂**（归一化角度无量纲），无阶乘：

```
P(u,v) = D10*u + D01*v + D20*u² + D11*u*v + D02*v²
       + D30*u³ + D21*u²*v + D12*u*v² + D03*v³
       + D40*u⁴ + D31*u³*v + D22*u²*v² + D13*u*v³ + D04*v⁴
       + D50*u⁵ + D41*u⁴*v + D32*u³*v² + D23*u²*v³ + D14*u*v⁴ + D05*v⁵
E_detector = P(u,v) + ε,    y_detector = v
```

默认 `ε` 是 FWHM=8 meV 的高斯有效总能量响应，σ=8/√(8 ln 2)≈3.397 meV。通过对几何落点分布进行固定高斯卷积来边缘化能量随机量，比重复抽取有限能量光线更稳定；不在每次拖动后重标定横轴。探测器图是期望计数，开启 Poisson 后是计数实现。

**8 meV 不是 Cc。** 首版不将源、色差、探测器分别各设为 8 meV。基线表示合并的有效响应；额外高斯能量模糊可按方差合成，像素化另行作用。真实能角色差耦合、设备传递矩阵、校正器耦合、衍射和实验标定不在首版中冒充实现。

## 合成情景

支持横/纵孔径比例、几何非色散方向狭窄接受窗口、额外能量高斯响应、非色散方向高斯 PSF、总计数、均匀背景、Poisson 噪声和视野大小。窗口明确是 `|u|` 角接受窗口，**不是原脚本的能量选择狭缝**；原能量选择模型仅在 legacy 模式保留。有限源/完整能角相关狭缝与真正色差耦合需进一步模型审查，首版不以错误代理冒充。

滑块量程和情景范围是合成练习设置，不是设备安全限值。随机题不再受总几何位移预算压缩，初始像差或补偿均可能出视野，此时明确提示被裁切比例；超出 0.1% 时不报告有效 FWHM。扩大视野不改变隐藏系数和答案，但会影响能量像素间距；极端场景在最大视野下也不保证无裁切。纵横轴单位不同，显示尺寸只是显式的能量—角度图布局，不能当作真实探测器几何放大率。

## 已知不可辨识性

对称孔径下，同时改变所有 u 的奇次幂项的符号可产生相同图像，因此单张图不保证唯一的全系数反演；增加四/五阶并不消除这种不可辨识性。界面将“与生成标签的差距”和可观察的谱宽/形状分开；后续网络需处理等价解、额外观测或调节轨迹。生成标签误差不能解释为实验像差测量误差。

## 验证层级

数值单元测试 → legacy 离线回归 → 本地 HTTP/浏览器交互验证 → 用户在 Windows 浏览器经 WSL2 localhost 操作验收。前三级不等于真实仪器或实验准确性验收。实际记录见 `docs/validation.md`。
