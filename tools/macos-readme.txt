EELS 像差调节练习器 — macOS 版

1. 将整个 ZIP 解压到本地文件夹，不要在压缩包中直接运行。
2. 双击 EELS-Practice.app，程序会自动用默认浏览器打开。无需安装 Python、Node 或浏览器内核。
3. 本版按成品文件名标注的处理器架构构建：arm64 用于 Apple Silicon，x86_64 用于 Intel Mac。
4. 关闭最后一个该程序网页（或离开该网页）后，一般约 5～10 秒退出后台程序，不关闭其他浏览器页面。
   同一启动链接打开多个标签时，全部关闭才退出；重复双击 App 会启动独立实例。
   普通刷新有 5 秒断线宽限，刷新会重建练习会话，先按需导出。
5. 后台标签不依赖 JS 定时心跳。浏览器崩溃或丢弃标签后也会尝试回收程序。
   若连接中断未恢复，请重新双击 App；不要收藏随机端口链接。
6. 本构建未使用 Apple Developer ID 签名，也未公证。首次打开若被 macOS 拦截，请在 Finder 中按住 Control
   点按 App 后选择“打开”，并确认来源；不要关闭 Gatekeeper 或执行来源不明的终端绕过命令。
7. 若启动后 90 秒仍无页面连接，程序会自动停止并提示。请检查默认浏览器和本机代理。
8. 使用系统浏览器下载 PNG/NPZ；请自行选择保存位置。练习模式 NPZ 包含答案。
   数据只在内存中，退出或刷新不会自动保存；程序不会自动安装、联网更新或开机自启。
9. 仅离线合成模型，不连接仪器，未作真实像差/设备标定；8 meV 为有效总响应 FWHM。

调节：↑↓ 选项；双击行末 ↔ 或 Enter 开始；滚轮 / ←→ 改系数；↑↓ 改步长；
Enter / 左键确认；Esc 撤销。三页共 20 项同时叠加。详细说明在网页下方。

分发包含运行所需的 Python、NumPy、Pillow 及相关库，许可见 THIRD-PARTY。
未内置 Chromium / Electron。实际 ZIP 和解压体积见 build-report.json，不承诺固定大小。
