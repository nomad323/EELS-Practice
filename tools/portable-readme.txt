EELS 像差调节练习器 — Windows x64 便携版

1. 将整个 ZIP 解压到本地文件夹，不要在压缩包中直接运行。
2. 双击 EELS-Practice.exe，自动用默认浏览器打开。无需安装 Python、WSL、Node 或浏览器内核。
3. 不要移走 _internal 文件夹或仅复制 exe；移动时请移动整个 EELS-Practice 文件夹。
4. 关闭最后一个该程序网页（或离开该网页）后，一般约 5～10 秒退出后台程序，不关闭其他浏览器页面。
   同一启动链接打开多个标签时，全部关闭才退出；重复双击 exe 会启动独立实例。
   普通刷新有 5 秒断线宽限，刷新会重建练习会话，先按需导出。
5. 后台标签不依赖 JS 定时心跳。浏览器崩溃或丢弃标签后也尝试回收程序。
   浏览器主动丢弃/断开后台页面可能导致退出；若连接中断未恢复，重新双击 exe。
   完全休眠/挂起期间不能承诺即时退出。不要收藏随机端口链接，下次仍双击 exe。
6. 若启动后 90 秒仍无页面连接，程序自动停止并提示。请检查 Windows 默认浏览器、
   本机代理或安全软件；不要改为监听局域网，不要关闭防火墙或绕过安全警告。
7. 使用系统浏览器下载 PNG/NPZ；请自行选择保存位置。练习模式 NPZ 包含答案。
   数据只在内存中，退出或刷新不自动保存练习。便携版不会自动安装、联网更新或自启动。
8. 仅离线合成模型，不连接仪器，未作真实像差/设备标定；8 meV 为有效总响应 FWHM。
9. 界面字号、控件和图谱刻度随可用窗口空间放大；小窗口保留紧凑布局。
   字体异常偏小时，可先按 Ctrl+0 恢复浏览器 100% 缩放并最大化窗口。
   程序不修改浏览器缩放/系统 DPI，也不主动改变个人浏览器窗口。

调节：↑↓ 选项；双击行末 ↔ 或 Enter 开始；滚轮 / ←→ 改系数；↑↓ 改步长；
Enter / 左键确认；Esc 撤销。三页共 20 项同时叠加。详细说明在网页下方。

分发包含运行所需的 Python、NumPy、Pillow 及相关库，许可见 THIRD-PARTY 和 _internal。
未内置 Chromium / Electron。实际 ZIP 和解压体积由构建报告记录，不承诺固定大小。
未签名构建可能触发 Windows 信誉检查；先核对来源和 SHA256，有疑问联系提供者。
